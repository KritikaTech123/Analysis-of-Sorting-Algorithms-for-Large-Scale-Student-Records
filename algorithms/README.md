# Basic Sorting Algorithms

This module implements the three basic sorting algorithms assigned to Member 2:

- Bubble Sort
- Selection Sort
- Insertion Sort

The implementation works directly with the student-record dictionaries generated by Member 1.

## Supported sorting keys

- `Student_ID`
- `CGPA`
- `Marks`

All algorithms sort **in place** in ascending order and return a `SortMetrics` object containing:

- `comparisons`
- `swaps`
- `moves`

Execution time and memory measurement are intentionally left to the benchmarking member so that algorithm code does not contaminate the experiment measurement.

## Usage

From the project root:

```python
import csv
from algorithms.basic_sorts import bubble_sort, selection_sort, insertion_sort

with open("data/generated/random/students_1000_random.csv", newline="", encoding="utf-8") as f:
    records = list(csv.DictReader(f))

metrics = bubble_sort(records, key="CGPA")
print(metrics.as_dict())
print(records[:5])
```

For a generic dispatcher:

```python
from algorithms.basic_sorts import sort_records

metrics = sort_records(records, algorithm="insertion", key="Marks")
```

## Complexity

| Algorithm | Best | Average | Worst | Extra Space |
|---|---:|---:|---:|---:|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) |

Bubble Sort uses early termination when a pass makes no swap. Insertion Sort counts record shifts as moves and keeps `swaps = 0` because it does not perform element exchanges.
